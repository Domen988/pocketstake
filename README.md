# Pegged — stakeout with your phone

A PWA that shows Slovenian cadastre (GURS) parcels and boundary points on an
orthophoto, guides you to a point, and averages GPS to tape out its position.

**Pegged finds where the cadastre says a point is. Only a geodet can establish
a boundary.**

Status: phase 1 of 6 (map and data). Run tests with `npm test` (Node 18+, no
dependencies). Full README lands in phase 6.
